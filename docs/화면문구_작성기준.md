# 그룹웨어 화면 문구 — 업무용 표현 기준

목표: AI 가 쓴 듯한 말투(풀어 쓴 고유어 · 의인화 · 긴 줄표 · 친절한 해설체)를 **회사 업무 시스템의 표준 문구**로 바꾼다.
사용자는 사내 직원 · 파트너사 담당자다. 짧고 정확하게, 합니다체로.

## 1. 바꿀 대상 (화면에 보이는 것만)
- HTML 텍스트 · 버튼 · 라벨 · 제목 · 표 머리글 · placeholder · title(툴팁)
- alert / confirm / prompt / showAppToast / 안내 문구 · 빈 목록 문구 · 오류 메시지 (서버가 돌려주는 error 문자열 포함)
- 템플릿 문자열 안의 문장

## 2. 절대 바꾸지 않을 것
- **주석** (`//`, `/* */`, `<!-- -->`) — 손대지 않는다
- console.log / console.warn / console.info / console.error 의 문자열
- **데이터 값으로 쓰이는 문자열**: 상태값(승인완료 · 미승인 · 진행중 · 완료 · 보류 · 접수 …), 본부/팀/직급 이름, 카테고리 값, 옵션 value, 객체 키, id, 저장 키(gwXxx.v1), 비교(`===`, `includes`, `case`)에 쓰이는 문자열, 정규식, 시드 데이터. 확실하지 않으면 **바꾸지 않는다**
- 메뉴 이름 · 화면 제목 · 필드 라벨처럼 이미 명사형으로 정리된 짧은 단어 (예: 거래처 관리, 운행일지, 계약명)
- 고유명사 · 제품명 · 법령 문구 · 약관
- `${...}` 자리표시, HTML 태그 · 속성, `\n`, 따옴표 짝 — 그대로 유지. 바꾼 결과가 JS/HTML 문법을 깨면 안 된다
- 이미 업무적인 문장 (예: "공지사항이 수정되었습니다.", "조건에 맞는 상담 내역이 없습니다.") — 그대로 둔다

## 3. 바꾸는 규칙
### 3-1. 단어 (풀어 쓴 고유어 → 업무용 한자어/표준어)
| 지금 | 바꿀 말 |
|---|---|
| 고치다 · 고칠 수 있는 | 수정하다 · 수정 가능한 |
| 지우다 · 지우기 | 삭제하다 · 삭제 |
| 만들다 (계정 · 자료 · 업무) | 생성하다 · 등록하다 |
| 넣다 · 적다 (값) | 입력하다 · 등록하다 |
| 고르다 | 선택하다 |
| 누르다 (버튼) | 클릭하다 (또는 "~ 버튼을 선택하면") |
| 올리다 (파일) · 내려받다 | 업로드하다 · 다운로드하다 |
| 보이다 / 안 보이다 | 표시되다 / 표시되지 않다 |
| 받아 오다 · 가져오다 (서버) | 불러오다 · 조회하다 |
| 닿다 · 닿지 않다 (서버) | 연결되다 · 연결되지 않다 / 접속할 수 없다 |
| 두드려 보다 | 확인하다 |
| 풀리다 · 풀다 | 해제되다 · 해제하다 |
| 세다 · 셉니다 | 집계하다 |
| 쓰다 (사용) | 사용하다 |
| 남다 · 남기다 | 유지되다 · 보관하다 · 기록하다 |
| 바뀌다 · 바꾸다 | 변경되다 · 변경하다 |
| 맞추다 | 일치시키다 · 조정하다 |
| 막다 · 막히다 | 차단하다 · 제한되다 |
| 들어가다 · 들어오다 (화면/서버) | 접속하다 · 이동하다 |
| 알아보다 | 확인하다 |
| 붙이다 (파일) | 첨부하다 |
| 되돌리다 | 복원하다 · 원래대로 변경하다 |
| 끄다 / 켜다 (기능) | 사용 안 함 / 사용 (문맥에 따라 비활성화/활성화) |

### 3-2. 문장
- **긴 줄표(—)로 문장을 잇지 않는다.** 마침표로 나누거나, 쉼표 · 괄호 · 콜론으로 바꾼다.
  - 예) "포맷 지정 없음 — 어떤 형식이든 올릴 수 있습니다." → "포맷 제한 없음 (모든 형식 업로드 가능)"
  - 제목 옆 짧은 보조 설명의 "— 관리자만 고칠 수 있습니다" → "(관리자 전용)"
- **의인화 · 해설체 제거**: "그룹웨어가 대신 열어 주지 않습니다", "서버가 알아서 보냅니다", "그거면 충분합니다" 같은 표현 → 사실만 짧게.
- **확인창**: "~할까요?" → "~하시겠습니까?"
- **요청**: "~해 주세요" 유지 가능. "~하세요" 명령조 반복은 "~해 주세요"로.
- **실패**: "~하지 못했습니다" → "~에 실패했습니다" 또는 "~할 수 없습니다" (자연스러운 쪽)
- **완료 토스트**: "~했습니다" → "~되었습니다" (예: "복사했습니다" → "복사되었습니다")
- 해요체(~어요/~해요/~예요/~네요) → 합니다체
- 구어적 부사 제거 · 정리: 그냥, 알아서, 바로바로, 한꺼번에(→일괄), 미리(유지 가능), 통째로(→전체)
- 문장 안의 " · " 나열 → 쉼표(, ). 짧은 라벨/제목 안의 "A · B" → "A·B" (띄어쓰기 없는 가운뎃점). 표 머리글 · 배지 등 데이터 성격은 유지 가능.
- 지나치게 긴 해설 문장은 핵심만 남겨 1~2문장으로 줄인다. 단, **안내의 의미(조건 · 제한 · 경고)는 빠뜨리지 않는다.**

## 4. 출력 형식 (원본 파일은 절대 수정하지 않는다)
JSON Lines 파일 하나. 한 줄에 하나의 바꿈:
`{"file": "index.html", "line": 13519, "old": "원본 줄 안의 정확한 부분 문자열", "new": "바꿀 문자열"}`
- `line` 은 스냅샷 파일 기준 1부터 시작하는 줄 번호
- `old` 는 그 줄 안에 **정확히 한 번** 나타나는 부분 문자열(필요하면 앞뒤 글자를 넉넉히 포함해 유일하게). 여러 줄에 걸친 바꿈은 줄마다 따로.
- 같은 줄에 여러 바꿈이 있으면 겹치지 않게 여러 개로 쓰거나, 그 줄의 문장 전체를 old 로 잡아 한 번에.
- JSON 이스케이프 주의: 원본의 `\n` 은 JSON 안에서 `\\n`, 큰따옴표는 `\"`.
- 바꿀 것이 없는 문장은 쓰지 않는다.
